视频字幕工具

## 基础需求

1. 能加载 h264 h265 视频（直插优先；Chromium 无法硬解时用 ffmpeg 自动转 h264 预览副本兜底）
2. 能将视频中的音频转成文字（whisper.cpp CLI 子进程，json-full 输出获取 token 级时间戳）
3. 每段文字应该有其起始时间和结束时间
4. 断句（详见下方「断句设计」）
5. 合成：ffmpeg 硬字幕烧录，输出新视频
6. 字幕保存：JSON 工程文件（保留词级时间戳与断句元数据）+ 可导出 SRT；工程文件由应用数据目录统一管理，提供最近打开列表
7. 支持手动对字幕 语句的增删改（纯增删改；修正断句通过 新增+编辑+删除 完成，不做合并/拆分按钮）

## 技术栈

1. electron
2. react
3. typescript
4. whisper.cpp CLI 子进程接入，基于 large-v3-turbo 本地模型
5. ffmpeg（字幕烧录合成、h265 预览转码兜底）

## 模型分发

1. 模型不随应用打包；用户自行下载 large-v3-turbo gguf 模型文件（约 1.6GB）
2. 提供「拖入模型文件」交互：下载完成后将模型文件拖入应用完成置入，应用校验并记录路径
3. 应用内展示模型状态（未置入 / 已置入）

## 断句设计

### 目标

1. 不在中文词组内部断开（断句与换行都遵守），所有断点必须落在词边界
2. 不被 Whisper 分段边界强行切断句子，完整句子允许跨越多个 Whisper segment
3. 断点时间精确，使用真实时间戳而非按字数估算

### 主路径：本地断句

1. 转写时获取 token 级时间戳（whisper.cpp `token_timestamps` / `split_on_word`，CLI json-full 输出含每个 token 的时间）
2. 跨段合并成句：累积 token 直到句末标点（。？！?!…），重建完整句子
3. 词边界切分：用 `Intl.Segmenter`（granularity: word，Electron 自带 ICU，零额外依赖）把句子切成词单元
4. 字幕条组装：
   - 一句一条；不超过上限（默认每行 ≤16 字、最多 2 行、单条 ≤8 秒，均可配置）则直接作为一条字幕
   - 超长句 → 在词边界候选断点中拆分：优先二级标点（，、；：）之后，否则取最接近中点的词边界
   - 断点时间 = 断点后第一个词的首 token 时间戳；token 时间戳缺失时兜底按字符占比估算
   - 字幕条结束时间 = 句尾 token 时间 + 1 秒缓冲，且不超过下一句开始时间
5. 无标点兜底：按时长 + 字数上限在词边界强制断

### 换行规则（显示层）

1. 单条字幕最多 2 行，每行默认 ≤16 字
2. 换行点必须落在词边界：某词放不下当前行时整词移到下一行，绝不截断词组
3. 优先在二级标点（，、；：）处换行，其次取行容量内最接近行尾的词边界

### 兜底路径：手动 AI 断句（导入功能，不使用 API）

1. 「导出待断句文本」：每行一条原始转写（`#序号 文本`），支持全文导出和勾选时间段分块导出；同时提供一键复制的提示词模板（要求 AI：不得改动任何文字，仅在各句之间的词边界插入换行，保持标点/简繁/大小写原样）
2. 用户自行将文本粘贴给任意 AI，将结果按固定格式粘贴回来
3. 「粘贴导入」校验：拼接 AI 返回的全部文字，与原文逐字比对
   - 不一致 → 拒绝入库，报错并高亮差异，用户可重试
   - 一致 → 将每个断点的字符偏移映射到词边界（AI 断在词组内部时吸附到最近词边界并提示），再用词级时间戳生成时间轴

### 语言范围

中文为主设计断句/换行规则，兼容其他语言（`Intl.Segmenter` 语言无关）
